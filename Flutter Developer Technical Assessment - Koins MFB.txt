Flutter Developer Technical Assessment 
Fintech Mobile Application 
Duration: 6–8 Hours 
Technology Stack 
• Flutter (Latest Stable Version) 
• Dart 
• Git 
• REST API 
• Local Storage (SharedPreferences / Hive) 
• Any state management solution (Provider, Riverpod, Bloc, GetX, etc.) 
Scenario 
You have been hired by a digital bank to build a simple savings application. 
The application allows users to: 
• Login 
• View available savings plans 
• View savings plan details 
• Create a savings plan 
• View their savings dashboard 
The emphasis is on clean architecture, good UI, performance, and maintainable code rather than complex business  logic. 
Functional Requirements 
1. Login Screen 
Design a login page containing: 
• Email Address 
• Password 
• Login Button 
• Forgot Password (non-functional) 
• Register (non-functional) 
Validation 
• Email required 
• Valid email format 
• Password required 
• Minimum 8 characters 
On successful login, navigate to Dashboard. No authentication backend is required. Use mock authentication. Example Credentials
Email: test@bank.com 
Password: Password123
